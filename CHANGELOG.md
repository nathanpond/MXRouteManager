# Changelog

All notable changes to MXRouteManager are documented here.

## [1.0.0] - 2026-08-26

Initial release: a lightweight macOS menu bar app that creates MXRoute email forwarders in under ten seconds.

### Added

- Menu-bar-only app shell (SwiftUI `MenuBarExtra`, `.window` style, no Dock icon), macOS 15+
- Create-forwarder flow: async domain dropdown → validated alias field with live address preview → destination account picker → create with progress, confirmation, and one-click "Create Another"
- MXRoute API client (`listDomains`, `listEmailAccounts`, `createForwarder`) with typed error mapping and header auth (`X-API-Key`/`X-Server`/`X-Username`)
- Credential management: API key in the macOS Keychain via `KeychainService` (service `MXRouteManager`, account `api-key`); server hostname and username via `@AppStorage`; Settings form with save-and-clear SecureField and Remove
- Test Connection in Settings reporting the live domain count or the decoded API error
- First-run welcome guidance with numbered setup steps, and helpful empty states with Reload
- Visual design pass: material background, SF Symbols, consistent type scale, light + dark
- App icon (generated by `scripts/generate-appicon.swift`), README, sandboxed Release build with outgoing-network entitlement
- 55 unit tests (Keychain round-trip, settings model, API client via URLProtocol mocks, alias validation)

### Fixed

- Keychain presence checks are attributes-only, preventing a launch-blocking permission prompt after binary signature changes
- First-run "Open Settings…" button uses the `openSettings` environment action (a styled `SettingsLink` with an attached gesture silently swallowed the action)
