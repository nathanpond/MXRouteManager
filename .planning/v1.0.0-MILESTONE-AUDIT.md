## Cross-Phase Integration: 10/10 connections verified

All expected connections traced through source with file:line evidence by the integration checker — single AppSettings instance across both scenes; CreateForwarderModel app-scoped and sharing it; all Keychain access behind AppSettings/KeychainService (zero SecItem references in views); Test Connection and the create flow both routed through MXRouteClient.live(settings:); AliasValidator gating Create; isConfigured gating first-run vs form (openSettings action post-fix); force:true empty-state reloads; request-time-only secret reads with attributes-only presence checks; icon pipeline through actool into the installed /Applications bundle (plus network entitlement confirmed on the signed binary).

## E2E Flows: 4/4 complete

- **A — First run:** unconfigured → welcome → Open Settings → save credentials → Test Connection → create form. Complete.
- **B — Core value:** popover → cached domains → validated alias → destination → Create → server-truth confirmation → Create Another. Complete.
- **C — Error paths:** decoded API errors in Settings and inline in the popover; cancellation guards prevent stale state on domain switch. Complete.
- **D — Persistence:** @AppStorage for server/username/last-domain, Keychain for the key, hasAPIKey recomputed prompt-free at launch. Complete.
