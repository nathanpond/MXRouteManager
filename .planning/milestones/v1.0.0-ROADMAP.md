# Milestone v1.0.0: MVP

**Status:** ✅ SHIPPED 2026-08-26
**Goal:** Ship a menu bar app where a configured user can create an MXRoute email forwarder end-to-end in under ten seconds.
**Phases:** 1-5
**Total Plans:** 15

## Overview

A lightweight macOS menu bar app (SwiftUI MenuBarExtra) for creating MXRoute email forwarders: pick a domain, type an alias, pick the destination account, create. API key lives in the Keychain; the whole flow takes seconds. Built greenfield from the Xcode SwiftData template in two days (2026-08-25 → 2026-08-26), 66 commits, ~2,700 lines across app, tests, scripts, and docs.

## Milestone Summary

**Decimal Phases:** none.

**Key Decisions:**

- Create-only MVP; forwarder list/delete deferred to v2 (core value is fast creation)
- Destination picker limited to accounts on the selected domain (one API call)
- API key in Keychain only; X-Server/X-Username in @AppStorage (only the key is secret)
- SwiftUI + Foundation only, no third-party dependencies; macOS 15 minimum
- Keychain presence checks attributes-only; secret reads at point of use
- MXRouteClient credentials as a Sendable value snapshot, injectable session/baseURL for URLProtocol mocking
- App-scoped CreateForwarderModel so caches survive popover close (enables the <10s repeat flow)
- Programmatic `openSettings` environment action for prominent Settings buttons (styled SettingsLink + gesture swallows the action)

**Issues Resolved:**

- `.gitkeep` bundle-Resources collision under synchronized groups (Phase 1)
- Test-runner hang from Keychain ACL prompt at launch after entitlement change (Phase 3)
- Cross-suite MockURLProtocol race under Swift Testing parallelism (Phase 3)
- First-run Open Settings button silently dead from gesture arbitration (Phase 5, user-found)

**Issues Deferred:**

- v2 backlog: MGMT-01 forwarder list/delete, MGMT-02 free-text destinations, MGMT-03 launch-at-login

**Technical Debt Incurred:**

- Release build signed for local development (`get-task-allow`) — revisit only if distributing
- `kata-test-1`/`kata-test-2` forwarders remain on the account from checkpoint testing (deletable in panel)
