  <action>
Create `MXRouteManager/Services/MXRouteClient.swift` (auto-joins the app target). `import Foundation` only. Header comment: the single place the app talks to `https://api.mxroute.com`; every request is authenticated and every failure leaves here as an `MXRouteError`.

**Credentials** — a value snapshot, not a closure:

```swift
nonisolated struct MXRouteCredentials: Sendable, Equatable {
    let server: String
    let username: String
    let apiKey: String

    init?(server: String, username: String, apiKey: String?) {
        // trim all three; return nil if any is empty or apiKey is nil
    }
}
```

WHY a snapshot instead of a `() throws -> MXRouteCredentials` provider closure: `AppSettings` is `@Observable` and MainActor-isolated, so a stored closure capturing it would make the client non-`Sendable` and drag actor-isolation problems into every call site and test. The client is cheap and is constructed per user action (button press), so reading credentials at construction time is always fresh enough.

**Client**:

```swift
nonisolated struct MXRouteClient: Sendable {
    static let productionBaseURL = URL(string: "https://api.mxroute.com")!

    let credentials: MXRouteCredentials?
    let session: URLSession
    let baseURL: URL

    init(credentials: MXRouteCredentials?, session: URLSession = .shared, baseURL: URL = MXRouteClient.productionBaseURL) { ... }
}
```

`credentials` is Optional so an unconfigured app is representable; requests then fail with `.notConfigured` before any network call.

**Path encoding** — a domain name goes into the URL path and must be escaped per segment:

```swift
private static let pathSegmentAllowed: CharacterSet = {
    var set = CharacterSet.urlPathAllowed
    set.remove("/")
    return set
}()
```

Do NOT use plain `.urlPathAllowed` (it permits `/`, so a hostile or malformed domain string could inject extra path segments) and do NOT use `URL.appending(path:)` (it treats `/` as a separator). Build the URL as `baseURL` + `"/"` + encoded components joined by `/`, then `URL(string:)`; if encoding or `URL(string:)` returns nil, throw `MXRouteError.invalidRequest(message: "Could not build a URL for \(components.joined(separator: "/")).")`.

**Request builder**:

```swift
private func makeRequest(method: String, pathComponents: [String], body: Data?) throws -> URLRequest
```

- `guard let credentials else { throw MXRouteError.notConfigured }`
- Set `httpMethod`, `timeoutInterval = 30`, and headers: `X-API-Key` = `credentials.apiKey`, `X-Server` = `credentials.server`, `X-Username` = `credentials.username`, `Accept` = `application/json`. When `body != nil`, also `Content-Type: application/json` and `httpBody = body`.
- `cachePolicy = .reloadIgnoringLocalCacheData` — a cached domain list would make a re-test after fixing credentials silently return the old answer.

**Response pipeline** — one function every endpoint goes through:

```swift
private func send<T: Decodable & Sendable>(_ type: T.Type, method: String, pathComponents: [String], body: Data? = nil) async throws -> T?
```

In exactly this order:

1. `let request = try makeRequest(...)`.
2. Perform: `do { (data, response) = try await session.data(for: request) } catch let error as MXRouteError { throw error } catch { throw MXRouteError.network(message: error.localizedDescription) }`. WHY the re-throw arm: a mocked `URLProtocol` can surface an `MXRouteError` and it must not be re-wrapped as a network failure.
3. `guard let http = response as? HTTPURLResponse else { throw MXRouteError.invalidResponse }`.
4. Decode, remembering the failure instead of swallowing it:
```swift
var envelope: APIEnvelope<T>?
var decodingFailure: String?
if !data.isEmpty {
    do { envelope = try JSONDecoder().decode(APIEnvelope<T>.self, from: data) }
    catch { decodingFailure = error.localizedDescription }
}
```
5. `let succeeded = (200..<300).contains(http.statusCode) && (envelope?.success ?? true)`; if `!succeeded`, `throw Self.failure(status: http.statusCode, body: envelope?.error)`. Checking the status FIRST is what makes an HTML 500 page (which cannot decode) map to a server error rather than a decoding error.
6. If `envelope == nil`, and `decodingFailure` is set → `throw MXRouteError.decoding(message: decodingFailure!)`; if `decodingFailure` is nil the body was empty → `return nil` (the 201-create shape).
7. `return envelope?.data`.

**Failure mapping**:

```swift
static func failure(status: Int, body: APIErrorBody?) -> MXRouteError {
    if let body {
        if status == 401 || body.code == "UNAUTHORIZED" { return .unauthorized(message: body.message) }
        return .api(code: body.code, message: body.message, field: body.field)
    }
    if status == 401 { return .unauthorized(message: "MXRoute rejected these credentials.") }
    return .api(code: "HTTP_\(status)", message: HTTPURLResponse.localizedString(forStatusCode: status), field: nil)
}
```

Make it `static` (not private) so tests can exercise the table directly if useful. Note it maps 401 to `.unauthorized` even when the body decodes — CONF-04 must distinguish "your key is wrong" from every other failure.

**Endpoint**:

```swift
func listDomains() async throws -> [String] {
    guard let domains = try await send([String].self, method: "GET", pathComponents: ["domains"]) else {
        throw MXRouteError.decoding(message: "The domains response contained no data.")
    }
    return domains
}
```

**Live factory** — in a separate `@MainActor extension MXRouteClient` at the bottom of the file:

```swift
@MainActor
extension MXRouteClient {
    static func live(settings: AppSettings, keychain: KeychainService = .shared, session: URLSession = .shared) -> MXRouteClient {
        let key = (try? keychain.load()) ?? nil
        return MXRouteClient(
            credentials: MXRouteCredentials(server: settings.serverHostname, username: settings.username, apiKey: key),
            session: session
        )
    }
}
```

`(try? keychain.load()) ?? nil` flattens the double Optional; a Keychain read failure becomes "no credentials", which surfaces as `.notConfigured`.

Constraints:

- Do NOT add `listEmailAccounts` or `createForwarder` here — plan 03-03 owns them and will extend this same file.
- Do NOT add caching, retry, or rate-limit backoff. `X-RateLimit-*` headers exist but the MVP makes a handful of calls; retries would hide auth failures behind delays.
- Do NOT log, `print`, or include headers in any error message — `MXRouteError.network(message:)` must carry `error.localizedDescription` only, never the request.
- Do NOT make the client a class or a singleton, and do NOT hold a reference to `AppSettings`.
- Do NOT add `#if DEBUG` test hooks; injection is via the `session`/`baseURL` init parameters.

Create `MXRouteManagerTests/MockURLProtocol.swift` (auto-joins the test target). `import Foundation`. This is test infrastructure shared with plan 03-03 — no `@Test` functions in this file.

```swift
final class MockURLProtocol: URLProtocol {
    nonisolated(unsafe) static var handler: ((URLRequest) throws -> (HTTPURLResponse, Data))?

    override class func canInit(with request: URLRequest) -> Bool { true }
    override class func canonicalRequest(for request: URLRequest) -> URLRequest { request }

    override func startLoading() {
        guard let handler = MockURLProtocol.handler else {
            client?.urlProtocol(self, didFailWithError: URLError(.badServerResponse))
            return
        }
        do {
            let (response, data) = try handler(request)
            client?.urlProtocol(self, didReceive: response, cacheStoragePolicy: .notAllowed)
            client?.urlProtocol(self, didLoad: data)
            client?.urlProtocolDidFinishLoading(self)
        } catch {
            client?.urlProtocol(self, didFailWithError: error)
        }
    }

    override func stopLoading() {}
}
```

This exact shape was typechecked during planning against the test target's flags (`-swift-version 5 -enable-upcoming-feature ApproachableConcurrency`); `nonisolated(unsafe)` on the static handler is what keeps it compiling without an actor.

Add these helpers in the same file:

- `func makeMockSession() -> URLSession` — `let config = URLSessionConfiguration.ephemeral; config.protocolClasses = [MockURLProtocol.self]; return URLSession(configuration: config)`. WHY `ephemeral` + a fresh session per test: `URLSession.shared` ignores `protocolClasses`, so a mock registered there would silently let real traffic out.
- `func makeResponse(_ status: Int, url: URL) -> HTTPURLResponse` — `HTTPURLResponse(url: url, statusCode: status, httpVersion: "HTTP/1.1", headerFields: ["Content-Type": "application/json"])!`.
- `extension URLRequest { var capturedBody: Data? }` — return `httpBody` when present; otherwise drain `httpBodyStream` into a `Data` with a 4096-byte buffer (open/close the stream, `defer` the buffer deallocation). **This is load-bearing**: `URLProtocol` receives POST bodies as a stream and `request.httpBody` is `nil`, so plan 03-03's body assertions would silently pass against `nil` without it.
- `let mockBaseURL = URL(string: "https://api.mxroute.test")!` — a constant test base URL, so a mistakenly un-mocked request cannot reach the real API.

Constraints:

- Do NOT register `MockURLProtocol` globally via `URLProtocol.registerClass` — session-scoped registration only, so nothing leaks into other suites.
- Do NOT put `@Test` functions or fixtures for a specific endpoint in this file.
- Do NOT reference `KeychainService.shared` or `UserDefaults.standard` anywhere in the test target.
